# Cidade Dorme — Mistério na Vila

Jogo de navegador 2D inspirado na brincadeira Cidade Dorme.

## Como jogar
1. Extraia o ZIP.
2. Abra `cidade_dorme_corrigido.html` no Safari, Chrome, Edge ou outro navegador moderno.
3. Escolha a quantidade de moradores e seu papel.
4. À noite, use sua habilidade quando houver uma ação disponível.
5. Durante o dia, vote em quem você suspeita ser o sabotador.

## Papéis
- **Sabotador:** tenta eliminar os moradores.
- **Detetive:** investiga alguém durante a noite.
- **Médico:** protege alguém durante a noite.
- **Morador:** tenta descobrir o sabotador por meio das pistas e da votação.

## Observações
- O jogo roda localmente e não precisa de internet, conta ou servidor.
- É uma partida solo contra personagens controlados pelo jogo.
- Se tocar no arquivo abrir apenas uma prévia, use o menu de compartilhamento/abrir com e selecione Safari ou Chrome.
